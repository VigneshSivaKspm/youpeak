WHY v2 CAME OUT "SIMPLIFIED" — AND WHAT v3 CHANGES
--------------------------------------------------
1. ChatGPT REWRITES your prompt before it draws. It shortens it and often
   drops the quality words. v3's master prompt orders it to pass every prompt
   through WORD FOR WORD.
2. The first words set the medium. "A 3D icon of..." or "a cute emoji..."
   tells the model "flat app icon / sticker". v3 starts every prompt with
   "Ultra-detailed photorealistic 3D product render of...".
3. "Clay", "cute", "Pixar" and "chunky" push toward toy-like, low-detail
   art. v3 replaces them with real, physical materials: polished 22-karat
   gold with a milled edge, frosted borosilicate glass, glossy ceramic glaze,
   pebbled leather with stitching, anodized aluminium.
4. v3 names the render pipeline (Cinema 4D + Octane, path tracing,
   ray-traced reflections, global illumination, subsurface scattering), a
   real lens (100mm product lens) and a real studio lighting setup.
5. Every prompt ends with a STRICTLY NOT list that bans flat, vector,
   cartoon, clip-art, sticker, outline, cel-shading and low-poly.

HOW TO USE THIS FILE
--------------------
1. Use ChatGPT with image generation. Start a NEW chat per group (Brand,
   Hero, Personas, Screens, Icons, Emojis, Illustrations, Backgrounds).
2. Paste the MASTER PROMPT (section 0) first. Wait for "Ready".
3. Copy ONE prompt at a time: only the text between  >>>  and  <<<.
4. STYLE-ANCHOR TRICK (this matters most for consistency):
   a) Generate icon 5.1 (trophy) first, and regenerate it until it's perfect.
   b) Download it. In every later chat, upload it with your first prompt and
      add this line: "Use the attached image as the STYLE REFERENCE: match its
      render quality, materials, lighting, camera angle and padding exactly."
5. If a result still looks flat or simplified, use the fix-up phrases in
   section 10 (the first one is written for exactly that problem).
6. Sizes to pick in ChatGPT: Square 1024x1024 · Landscape 1536x1024 ·
   Portrait 1024x1536. Compress afterwards (tinypng.com / squoosh.app) to under
   200 KB, and save with the exact FILE name into public/assets/ (icons/,
   emoji/ and bg/ subfolders as marked).

DO NOT GENERATE (trademarks, so download the official files instead):
   Google Play / App Store badges · Razorpay, UPI, PhonePe, GPay, Paytm logos ·
   real people's faces · screenshots of other companies' apps
